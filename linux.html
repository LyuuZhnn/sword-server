🐧 Linux Lab

Linux Command Reference untuk TJKT

📂

ls

Menampilkan isi direktori.

ls
📁

cd

Berpindah direktori.

cd nama_folder
📍

pwd

Menampilkan lokasi direktori saat ini.

pwd
📄

touch

Membuat file kosong.

touch file.txt
📂

mkdir

Membuat direktori baru.

mkdir folder
📋

cp

Menyalin file atau folder.

cp file.txt backup.txt
🚚

mv

Memindahkan atau mengganti nama file.

mv file.txt folder/
🗑️

rm

Menghapus file.

rm file.txt
👀

cat

Menampilkan isi file.

cat file.txt
✏️

nano

Membuka editor teks terminal.

nano file.txt
🔐

chmod

Mengubah permission file.

chmod 755 file.sh
👤

whoami

Menampilkan user yang sedang digunakan.

whoami
💾

df

Melihat penggunaan storage.

df -h
🧠

free

Melihat penggunaan RAM.

free -h
🌐

ip

Melihat dan mengatur informasi jaringan.

ip addr
📡

ping

Menguji konektivitas ke host.

ping 8.8.8.8
🔎

ss

Melihat koneksi dan port jaringan.

ss -tuln
📦

apt

Mengelola paket pada Debian/Ubuntu.

apt update
⚡

systemctl

Mengelola service pada sistem Linux yang menggunakan systemd.

systemctl status nama-service
📜

history

Melihat riwayat command yang pernah dijalankan.

history
